# Лабораторна робота №3 з Python

## Структура проєкту

* `task1.py` — Обробка виключень (`try/except/else/finally`) та контекстний менеджер (`with`).
* `task2.py` — Власна ієрархія виключень (`ValidationError`) та ланцюжки помилок (`raise ... from`).
* `task3.py` — Організація коду в модулі та розмежування виконання (`if __name__ == "__main__":`).
* `task4.py` — Документування коду (docstrings у стилі Google), анотації типів та інтроспекція (`help`, `__doc__`).
